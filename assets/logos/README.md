# Company logos for the work side

Each job's logo tile loads that company's site icon from Google's favicon service
(`https://www.google.com/s2/favicons?domain=<domain>&sz=128`). If the image fails to load,
the tile falls back to the company's initials.

To use a sharper logo instead, drop a square PNG here (about 128×128px) and change that
job's `<img src>` in ../../index.html to `assets/logos/<file>.png`.
