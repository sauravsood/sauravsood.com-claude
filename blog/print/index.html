The printer that wouldn’t listen

I wanted my iPhone to print shipping labels. Claude wrote the app in about an hour, and we spent the rest of the day reviving a Raspberry Pi from 2015. By evening, labels were printing.

print.sauravsood.com ↗
Chapter 1

The ask

  • I ship Butter Beings orders from home on 4×6 courier labels. My label printer, a TSC TA220, has only an Ethernet port and its own printer language.

  • My work laptop is locked down, so I can’t install a driver, and iOS has no way to send a job to a raw label printer. I asked Claude to build a web app that prints over Wi-Fi.

  • A website on the internet can’t see a printer on my home network, so the app needs a small computer sitting next to the printer. When Claude suggested a Raspberry Pi, I remembered I already had one, cabled up and supposedly online.

Chapter 2

The Pi

  • It wasn’t online. I sent Claude a phone photo of its screen.Kernel panic - not syncing: VFS: Unable to mount root fsCauseThe memory card had worked loose.FixI pushed the card back in, and it booted.

  • Once it booted, we found a Pi 2 running Raspbian from February 2015, still on the default login. That was far too old to run anything current.

Chapter 3

The card

  • Reinstalling the OS usually means writing a new card from a PC, and I don’t have one. Claude wrote a script that turns the old Pi into its own installer: it downloads the current OS and writes it to a new card in a USB reader.

  • 64 GB card detected as about 1 GBCauseClaude first found and fixed an overflow bug in its own size check, but the card still read 1 GB. The real problem was my USB card reader, which is too old for cards over 32 GB.FixThe script now explains this instead of just failing.

  • Download stopped at 19% (and once, a checksum mismatch)CauseThe connection kept cutting the big OS download off partway.FixThe script now fetches 8 MB pieces, retries each one up to 20 times and checks the whole file at the end.

Chapter 4

The cloud

  • Cloudflare’s install command carries a secret token about 200 characters long, and I wasn’t going to type that on the Pi’s keyboard. I logged in to the Pi from the laptop so I could paste it.

  • Could not get lockCauseThe fresh OS was still installing its own first-boot updates.FixThe installer now waits for them, up to 15 minutes.

  • illegal base64 dataCauseClaude’s first guess was wrong, and it said so. I had pasted Cloudflare’s whole suggested command, cloudflared service install eyJ..., instead of just the token.FixThe installer now picks the token out of whatever I paste.

  • Cloudflare’s menus no longer matched any guide, including Claude’s first README. I complained that steps were getting skipped, and Claude rebuilt the instructions around my screenshots, grouped by where each step happens.

Chapter 5

The house

  • My Airtel fibre router has a TP-Link Deco mesh behind it, and the mesh runs its own network. I moved the Pi and the printer from the mesh onto the main router.ssh: connection timed out, and the tunnel went downCauseThe Pi picked up a new IPv6 address from the router but kept its old IPv4 address from the mesh, so nothing could reach it.FixA reboot, so it gets a fresh address on the main network.

Chapter 6

The first label

  • After the reboot, the tunnel came back up. I opened print.sauravsood.com, uploaded a courier label and tapped Print.

  • The printer fed out the label. My iPhone, which can’t talk to a label printer at all, had just printed one through a web page and a Raspberry Pi from 2015.

Chapter 7

Away from home

  • Later, I needed the Pi while I was away from home.ssh: connection timed outCauseThe Pi’s address only works on my home Wi-Fi, and I still had just the locked-down laptop and the iPhone.FixThe Pi already runs a Cloudflare tunnel for the print page, so I added a second address to it, ssh.sauravsood.com, with browser-based SSH behind the same email code. Now the Pi’s terminal opens in a browser tab, with no open ports and nothing installed.

  • Tunnel status: DownCauseThe Pi itself was offline.FixI switched it off and on again.

  • Local SSH failing at home, while the tunnel was healthyLikely causeProbably power saving on the Pi’s USB Wi-Fi adapter.FixTurn Wi-Fi power saving off on the Pi.

  • I did the same for a server on AWS. The full story is in A terminal in a browser tab.

The running joke

  • For most of the day, my best debugging tool was a phone photo of the Pi’s screen. Each problem ended up as a fix in the installer or the README, so the next person setting up a Pi shouldn’t run into it.

What I’d tell someone else

  • If you can’t install anything on your own devices, put the software on a box you control and use it from a web page.

  • A 2015 Pi is plenty for a print server once it runs a current OS.

  • The errors about a 1 GB card, bad base64 and a busy lock each pointed away from the real cause.

The app is plain Python plus poppler, a PDF tool, so it runs on the old Pi without extra packages. It crops A4 courier sheets down to the 4×6 label, shows a preview and sends the job to the printer. The code is open source at github.com/sauravsood/print-bridge.
