Print

Shipping labels from my iPhone to a printer that only has an Ethernet port. The code took an hour. The hardware took the rest of the day.

print.sauravsood.com ↗

I ship Butter Beings orders from home, on 4×6 inch courier labels. The label printer, a TSC TA220, only has an Ethernet port and speaks its own language. My work laptop can’t install drivers. My iPhone can’t talk to it at all.

So I asked Claude for a web app that could. Open a page, drop in a label PDF, tap Print.

How it works

A website can’t reach a printer at home. A small box next to it can.

  • 1 · PhoneOpen print.sauravsood.com and log in with a one-time code.
  • 2 · TunnelCloudflare carries it home. No ports opened on the router.
  • 3 · PiCrops the A4 courier sheet to the label, rotates it, and shows a preview.
  • 4 · PrinterPick copies, tap Print. The Pi sends it straight to the printer.

The day

Every error pointed somewhere else.

  • The Pi“Do I need one?” Turns out I had one. From 2015. It wouldn’t boot until I pushed the memory card back in.
  • No PCNo computer to reflash it, so Claude wrote a script that makes the old Pi install its own replacement.
  • 64 GB = 1 GBThe new card read as 1 GB. The USB reader was too old for big cards.
  • 19%Downloads kept dying. Now they come in 8 MB pieces, retried until they land.
  • The token“Not valid base64.” I’d pasted Cloudflare’s whole command, not just the key. The installer now picks it out.
  • Two networksA mesh Wi-Fi behind the fibre router means two networks in one house. I moved the cables. The Pi kept its old address.

The best debugging tool all day was a phone photo of the Pi’s screen. Each hurdle became a fix in the installer or the instructions, so the next Pi won’t hit it.

What I learned

  • BrowserCan’t install anything? Put the smarts on a box you own and give yourself a web page.
  • Old is fineA 2015 Pi is plenty, once it runs a current OS.
  • ScreenshotsDashboards change. Write steps for the screen in front of you.

It runs on plain Python and one PDF tool, small enough for the old Pi. The code is open source at github.com/sauravsood/print-bridge, with a one-line install.
