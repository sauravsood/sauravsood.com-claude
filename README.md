# sauravsood.com

Plain static site: no build step, host anywhere (GitHub Pages, Netlify, Cloudflare Pages).

```
index.html            homepage (the court)
assets/css/site.css   all styles; colours and fonts are tokens at the top
assets/js/site.js     theme toggle ("Lights"), rally ball, rep counter, dog
notes/index.html      blog index
notes/_template.html  copy to notes/<slug>/index.html for each post
lab/index.html        interactive research projects index; each project in lab/<slug>/
```

Design: the page is a hard court seen from above. The net splits work (above) from life (below).
Light mode is a day match, dark mode is a night session under floodlights.
